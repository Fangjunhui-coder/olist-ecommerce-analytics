## 定义和分档

- 全部订单最后下单日的次日为 R 参照日：**2018-10-18**。R 是参照日期减去用户最近一次已送达订单的下单日期，以自然日计；F 是已送达订单数；M 是这些订单的商品 GMV 之和。
- 全体用户 R 的三分位点是 198、339 天：R ≤ 198 为较近，198 < R ≤ 339 为中间，R > 339 为较久。
- 全体用户 M 的三分位点是 58.90、127.90 雷亚尔：M ≤ 58.90 为低，58.90 < M ≤ 127.90 为中，M > 127.90 为高。
- 分位点使用线性插值；相同数值必须进入同一档，故各档人数不必完全相等。R 的远近和 M 高低均为本样本的相对标签，不是通用经营阈值。
- R、F、M 的 3 × 2 × 3 个组合互斥，用户数和商品 GMV 可以加总。平均 M 是人均累计商品金额，平均客单价是本组 GMV 除以本组订单数，两者不同。

## 各分层的策略假设

每条建议均为后续可以验证的方案，不代表项目已经开展运营或产生效果。所有组的共同衡量方式：按目标用户随机分组，比较分组后 30 天内有至少一笔已送达订单的用户占比，并监测每名目标用户的优惠成本和退订率；应设置相同观察窗口。触达、实验分组、成本和退订数据不在本数据集中，需在真实业务中另行采集。

- **较近 / 1 单 / 高：**在购买后适当时间测试相关品类或补充商品推荐；对单次购买客户测试第二单激励；高金额客户优先测试非折扣权益并控制成本。
- **较近 / 1 单 / 中：**在购买后适当时间测试相关品类或补充商品推荐；对单次购买客户测试第二单激励；中等金额客户测试有门槛的轻量优惠。
- **较近 / 1 单 / 低：**在购买后适当时间测试相关品类或补充商品推荐；对单次购买客户测试第二单激励；低金额客户测试低成本个性化推荐。
- **较近 / 2 单及以上 / 高：**在购买后适当时间测试相关品类或补充商品推荐；对复购客户优先测试会员权益；高金额客户优先测试非折扣权益并控制成本。
- **较近 / 2 单及以上 / 中：**在购买后适当时间测试相关品类或补充商品推荐；对复购客户优先测试会员权益；中等金额客户测试有门槛的轻量优惠。

## 局限

RFM 使用历史数据整段的累计金额，不是获客渠道、利润或终身价值；记录末段的已送达订单稀少，不应直接把“较久”理解为真实流失，也不能直接对当下用户执行触达。90 天复购覆盖限制见阶段 1 补充说明。
