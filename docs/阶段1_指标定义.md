# 阶段 1 指标口径

- 人群：`delivered` 且订单 ID、下单时间有效的订单；保留送达时间异常订单。时间按照订单下单时间归属自然月，时间戳原样使用，未转换时区。金额以巴西雷亚尔（BRL）为单位。
- GMV：所选订单的商品明细 `price` 之和，**不含运费**；不是支付额、收入或利润。价格为数据表记录，不能识别退款、取消后的调整或真实成交净额。订单量为去重订单数；买家数为去重 `customer_unique_id` 数。一个用户可能跨月、跨品类出现，不可将各月或各品类人数直接相加。
- 客单价：GMV / 订单量；件单价：GMV / 商品明细行数。本数据一行商品明细对应一个订单商品项。跨品类订单会同时计入相应品类的订单数，故品类订单数与其客单价不可直接加总或作为整站订单客单价。
- 全观察期复购率：本次已送达订单下单时间覆盖 2016-09-15 12:16:38 至 2018-08-29 15:00:37；在该观察范围内，至少下单两次的独立买家数 / 至少下单一次的独立买家数。不同买家观察时长不同、数据有截断；这不是固定 30 天复购率，也不是长期用户留存。月度复购率为同一自然月内已送达订单至少两单的买家数 / 当月已送达订单买家数，与全观察期复购率不同；月度独立买家数不可相加得到全观察期买家数。
- 月环比：(本月值 − 上月值) / 上月值；上一月为 0 或缺失时记为空值，不当作 0%；复购率还单列环比的百分点变化。趋势覆盖首个至最后一个有已送达订单的月份，空月补零；首尾月覆盖可能不完整，时点附近订单可能未送达。数据截尾与已交付筛选会造成偏差，月度差异不能直接解释成业务增长或衰退。
- 品类：有官方英文翻译时使用英文；有葡萄牙语原名但无翻译时保留葡萄牙语原名并标记 `untranslated`；葡语名为空时标记 `unknown`。每行商品明细只计入一个品类。帕累托包括使累计 GMV **首次达到或超过 80% 的那个品类**。多品类订单各品类按商品行归属，其订单量不可跨品类加总。
- 州：使用收货客户的 `customer_state`；不连接 geolocation。所有州 GMV 可求和对账，跨州用户数不可简单相加。
- 结果是历史观察结果，不代表因果关系或运营效果。核心结果需要 SQL 与独立 pandas 复算一致后才能使用。

## 阶段 1 补充口径

- 运费总额为已送达订单商品明细 `freight_value` 之和；含运费 GMV 为商品金额加运费。这两者是补充指标，含运费 GMV 不等同于实收或净收入。
- 首单后 90 天复购率：以全部订单中最晚下单时间为数据截止时点，只纳入首笔已送达订单的下单日期距该截止日期至少 90 个自然日的用户；分子是其中在首单时间之后，且下单日期不晚于首单日期后第 90 天的另一笔已送达订单的用户数。等于首单时间的其他订单不算“首单后”；第 90 天的订单计入。截止日可能是不完整的一天，末日数据需谨慎解释。只基于数据里可识别的历史首单，并非证明客户在数据开始前没有购买。
- 数据末段缺少已送达订单，不宜认为名义截止时点前的所有复购都被完整观察；报告同时提供以最后一笔已送达订单的下单时间为截止时点的敏感性对照，该对照也不能证明此前的数据覆盖完整。
